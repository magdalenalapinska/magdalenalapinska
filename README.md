### 🚀 Ostatni duży projekt

**[Małopolska Weather Analysis (2016-2025)](https://github.com/magdalenalapinska/malopolska-weather-analysis)**
Mój najbardziej aktualny projekt zrealizowany w ramach przedmiotu Metody Obliczeniowe. 
* **Co to jest:** System do filtrowania, przetwarzania i wizualizacji dobowych wahań temperatur na podstawie surowych danych z IMGW. 
* **Jak to działa:** Napisałam w Pythonie skrypt, który czyści dziesiątki tysięcy rekordów z błędów i anomalii, a następnie przy pomocy środowiska MATLAB wyznaczyłam uśredniony trend klimatyczny z użyciem aproksymacji wielomianowej 6. stopnia.
